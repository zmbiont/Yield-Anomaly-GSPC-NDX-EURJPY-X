
# Yield-Anomaly-GSPC-NDX-EURJPY-X
Indicador Estadístico de Anomalías en Rendimientos Logarítmicos

## Descripción
Este programa NO es una estrategia de trading.
Es un indicador estadístico que mide condiciones anómalas en los rendimientos logarítmicos intradía del activo seleccionado.

## Activos soportados
- S&P 500 (^GSPC)
- Nasdaq 100 (^NDX)
- EUR/JPY (EURJPY=X)

## Metodología
- Cálculo de rendimientos logarítmicos intradía.
- Detección estadística de desviaciones extremas.
- Visualización de anomalías sobre la serie temporal.
